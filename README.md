- **İndir:** [Son sürüm (Releases)](../../releases/latest): Windows için `.exe`, Android için `.apk`

- **Kurulum ve kullanım:** [BENIOKU.md](BENIOKU.md)

Yapay zeka: bilgisayardaki Ollama modelleri (qwen2.5:14b, bge-m3, qwen2.5vl:7b) ya da internetten Google Gemini / OpenAI-uyumlu servisler.

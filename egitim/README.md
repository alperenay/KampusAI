# İsteğe bağlı model deney araçları

Bu klasör uygulamanın kurulumu ve normal kullanımı için gerekli değildir. Veri hazırlama, model denemeleri ve değerlendirme betiklerini içerir; bu araçların varlığı bir modelin eğitildiği veya uygulamaya entegre edildiği anlamına gelmez.

- Windows giriş noktası: `KampusAI-Egitim.bat`.
- Ayarlar: `ayarlar.json`; betikler: `scripts/`.
- Model, veri ve çıktı klasörleri `.gitignore` ile dağıtım dışında tutulur.
- API anahtarlarını, özel öğrenci verilerini ve lisansı uygun olmayan soru/verileri paylaşma.

Gereken donanım ve bağımlılıkları kullanılan betiğe göre kontrol et. Bu deney araçları, uygulamadaki hazır Gemma/Gemini/Ollama bağlantılarından ayrıdır.
